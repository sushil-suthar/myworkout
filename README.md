# Aesthetic Gym — 52 Week Workout Tracker

A mobile-first personal gym workout tracker designed for iPhone/Chrome/Safari.

Features:
- 52-week / 13-block training plan
- 6 training days per week
- Automatic current-workout sequence
- Upcoming workout calendar
- Missed-workout recovery
- "Do this today" and "Swap with today"
- Local workout logging
- Progress and adherence tracking
- Full-size exercise photos
- In-app YouTube demonstrations where verified videos are available
- Backup/restore of local workout data

## GitHub Pages

This repository is intended to publish directly from the root of the default branch.

After uploading the files:
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose the default branch (usually `main`) and folder **`/ (root)`**.
4. Save.
5. GitHub will publish the site at a `github.io` URL.

GitHub notes that publishing changes can take a few minutes.

## Data privacy

The site itself contains the workout program, not your workout history. Your completed workouts, weights, reps, notes and schedule changes are stored locally in the browser on the device where you use the app.

Use the app's **Progress → Export backup** feature periodically.

## Important

The repository can be public on GitHub Free, so do not put personal/private data into the repository. Your workout history should remain in local browser storage and should not be committed to GitHub.
